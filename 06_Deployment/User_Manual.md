# User Manual — Key Journeys

## Checkout
1. Sign in or use the approved guest flow.
2. Review cart.
3. Confirm address.
4. Select shipping.
5. Select payment.
6. Complete payment.
7. View order confirmation.

## Order Tracking
1. Open Orders.
2. Select an order.
3. View current status and milestones.

## Returns
1. Open an eligible delivered order.
2. Select Return.
3. Select reason.
4. Confirm return details.
5. Submit and track the request.
