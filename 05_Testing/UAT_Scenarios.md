# UAT Scenarios

- **UT-001 Registration:** Customer registers and logs in successfully.
- **UT-002 Cart:** Customer leaves and returns; cart remains available.
- **UT-003 Checkout:** Customer confirms address, shipping, discount and total.
- **UT-004 Payment:** Supported payment method completes successfully.
- **UT-005 Payment Failure:** Failed payment can be retried without duplicate order creation.
- **UT-006 Inventory:** Operations verifies stock reservation after order.
- **UT-007 Order Processing:** Confirmed order moves automatically into fulfillment.
- **UT-008 Tracking:** Customer sees shipment milestones from logistics events.
- **UT-009 Return:** Eligible delivered order creates a return request.
- **UT-010 Refund:** Approved return triggers refund workflow.
- **UT-011 Dashboard:** Business user validates dashboard KPIs against source data.
