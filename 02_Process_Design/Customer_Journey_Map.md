# Customer Journey Map

| Stage | Customer Action | Pain Point | Future Experience | KPI |
|---|---|---|---|---|
| Discover | Browse/search | Generic experience | Personalized discovery | CTR |
| Evaluate | View product | Limited context | Reviews/recommendations | Product conversion |
| Cart | Add items | Cart abandonment | Persistent cart/coupon clarity | Abandonment |
| Checkout | Enter details | Friction | Simplified checkout | Conversion |
| Pay | Select method | Failures | Multi-method + retry | Payment success |
| Order | Wait | No visibility | Real-time tracking | Support tickets |
| Receive | Delivery | SLA uncertainty | Notifications | Delivery SLA |
| Return | Request return | Manual process | Self-service workflow | Return TAT |
| Re-engage | Buy again | Limited personalization | Recommendations | Repeat purchase |
